# 兼容性与能力边界

本项目交付提示词与配置模板。文件检查、配置加载、角色发现、真实派发、工具执行和完整协作流程属于不同验收层次，不能相互替代，详见[安装与验收](安装与验收.md#验收层次)。

| 范围 | 当前口径 |
| --- | --- |
| Windows | 提供配置流程；已有接入层中取得过 DeepSeek/high 默认与显式派发、high 文件工具、max 显式完成的证据；不代表全新机器通过 |
| macOS / Linux | 提供通用提示词与路径语义，目标机安装及运行未测 |
| DeepSeek 官网 | `deepseek-flash` 为推荐预设；官网直连须由目标用户独立验收，已有接入层成功不代替官网验证 |
| 自定义提供方 | 允许用户确认提供方、实际模型 ID 和档位；协议、工具及跨提供方派发能力分别核实 |
| 具名角色 | 三份源模板须先装配公共正文，不能直接安装；成品不依赖模板仓库。各入口发现与运行能力须现场核实，无角色字段时注入装配后的指令并注明 |
| 混合模式 | 原生与第三方路径分别取得证据后才声称对应路径可用；不把候选摘要当完整白名单 |

完整安装合并、重复安装、失败恢复与回滚、全部具名角色运行、两个提供方完整混合流程、max工具能力、复杂任务质量、并发压测、40%交接、故障注入、缓存及成本收益，均需目标环境的对应证据。

固定技能基线只表示源码与入口声明可复核，不替代目标机技能可用性检查。私有事务清单、[验收场景](安装与验收.md#可重复验收场景)和[有效证据索引](路由排查.md#有效证据索引)提供恢复与复用方法；静态装配或隔离夹具通过不代表有效配置已加载，原子替换也不提供跨文件或并发事务保证。

规则约束代理行为，不构成请求级强制路由网关；不承诺所有入口具有相同能力，也不承诺成本或性能改善。

逐轮测试、诊断、复核和交接材料保存在仓库外。公开文档只保留最终能力边界，不收录原始日志、会话标识或个人环境快照。后续修复按[项目公开文件边界](../AGENTS.md#公开文件边界)更新用户说明。
