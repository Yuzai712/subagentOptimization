# 模型与提供方

## 配置选择

混合模式是默认意向，实际模式由[配置入口](../prompts/配置入口.md)根据用户确认选择。没有第三方配置时采用 native；技能缺失时停止配置，不因切换 native 跳过技能门槛。

第三方预设为 DeepSeek 官方 `deepseek-flash`，用户可以改用其它提供方和模型。确认项包括提供方、端点、真实模型 ID、常用档/复杂档、凭据环境变量名和派发入口支持情况。原生候选预设为 `gpt-6-luna/medium` 与 `gpt-6-luna/low`，不支持时让目标用户确认替代。

[模型选择示例](../config/模型选择示例.toml)只表达选择，不是完整的 Codex 配置；修改该文件不会自动改变本机运行状态。实际路由规则以[规则模板](../config/AGENTS.model-routing.md)为真源，由目标 Codex 渲染并合并。

hybrid 采用第三方优先，预设 DeepSeek Flash/high，复杂任务优先考虑 Flash/max；适合委派的实现、调查、测试及独立检查均适用。GPT 例外与默认派发条件详见规则模板，不再按模型梯队把 GPT 与第三方并列为日常默认。

## DeepSeek 官方接入

2026-11-04 核对的[DeepSeek Codex 接入文档](https://api-docs.deepseek.com/quick_start/agent_integrations/codex/)说明其提供 Responses 接口与模型目录。接入细节、模型能力和推理强度须以官方现行文档及目标账户实际结果为准，不复制原电脑的模型目录。

以下仅为独立提供方定义示意，目标版本核实后按需合并，不修改顶层主模型或静默切换主会话提供方：

```toml
[model_providers.deepseek]
name = "DeepSeek"
base_url = "https://api.deepseek.com"
env_key = "DEEPSEEK_API_KEY"
wire_api = "responses"
request_max_retries = 1
stream_max_retries = 1
stream_idle_timeout_ms = 300000
```

`env_key` 是环境变量名称，不是密钥。用户在本机安全设置对应变量；本项目不索取值。是否需要其它目录、模型元数据或兼容设置，按官方说明与目标版本处理。不能把某提供方的模型目录替换为仅含第三方模型的列表后，继续声称原生 GPT 候选保留可用。

## 混合模式的实际边界

定义两个提供方不等于同一子代理入口能在两者间选择。必须核实当前工具和接入层的真实派发方式，并分别用最小无敏感子代理任务验证 GPT 与第三方路径；普通 API 请求、配置加载和模型列表不能替代该验证。

当前入口若只能使用一个提供方，记录限制，交由用户选择 native 或补齐接入。本仓库不捆绑转换网关，不把某接入层的专用别名写成通用模型名，也不通过更改主会话提供方伪造混合配置成功。

自定义提供方不支持 Responses、工具调用、固定推理档或干净上下文派发时，分别记录缺口；不能将不支持的字段照搬进去。优先策略在派发前决定档位，执行中的同一代理保持档位固定。

## 显式覆盖与默认派发

[Codex 官方子代理说明](https://learn.chatgpt.com/docs/agent-configuration/subagents)说明派发参数、agents 默认值、父代理设置与角色配置的关系。具体优先级须按目标入口核实。

摘要缺失、实际模型与预期不符或需要验证默认路径时，按[路由排查](路由排查.md)检查；该文集中维护排查顺序和证据要求，避免在每份文档复制流程。普通任务复用同一入口和档位的有效证据，环境或默认值变化后才重验受影响部分。

现有接入层的专用模型标识可能与官方模型名不同。公开预设使用 `deepseek-flash`，目标机器保留自己的真实派发 ID；本机接入层验证不等于官网直连、其它提供方或其它机器也通过。

[官方钩子说明](https://learn.chatgpt.com/docs/hooks)提供部分工具路径的拦截或参数改写能力，但覆盖和运行位置有边界。钩子不能补出不存在的模型接入，安装前必须验证真实入口支持；本方案默认用路由规则与运行证据解决选择问题，不安装强制改写模型的钩子。
