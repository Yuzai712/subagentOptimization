# 以提示词交付可迁移的 Codex 协作配置

状态：已接受，2026-11-04。

公开仓库以提示词、规则模板和三个职责角色交付，不提供 Python 脚本，不分发完整用户配置、认证、历史会话和原始参考资料。目标 Codex 按实际版本与本地授权合并配置，保留用户主模型及无关配置。这样减少机器路径和接入层绑定，代价是安装执行依赖代理与目标入口能力，必须分层验收，不能承诺所有电脑仅复制文件即可获得相同运行结果。

mattpocock/skills 是配置前置硬条件，至少核实 handoff、grilling、domain-modeling、code-review、writing-for-agents 的来源及当前可用入口；缺失即停止。混合模式为默认意向，第三方提供方和模型由用户确认，默认推荐 DeepSeek 官方 deepseek-flash；没有第三方配置时使用原生 ChatGPT/GPT 模型。模型不可用时用户确认替代；已有第三方但入口不支持混合派发时，由用户选择原生模式或先补齐接入，不静默改变主会话提供方。

保留按需委派、三个职责角色、固定执行档位、实际上下文40%交接、有界重试与最多一次故障接替。角色不固定模型；独立检查按风险触发，非每次强制三阶段流水线。规则属于工作流约束，硬限制及运行效果须另有证据。

公共子代理约束在规则模板中维护一份，源角色只保留职责与装配占位符；安装时生成完整角色。这在减少维护副本的同时保留成品独立性，代价是源角色不能直接复制安装，必须验收装配结果。个人/团队安装范围与业务目标明确区分，恢复依据及有效证据索引留在目标机私有目录；场景验收与性能对照方法属于公开使用说明，实际运行记录保持私有。
