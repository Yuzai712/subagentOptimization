# 分流标签

本项目使用 mattpocock/skills 默认分流标签，不另设别名。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求齐备，可交代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或操作 |
| `wontfix` | `wontfix` | 不计划处理 |

技能提到分流角色时使用表中的实际标签。调整词汇时同时更新本表和远程标签，不静默增加同义标签。
