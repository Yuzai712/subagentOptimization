# 领域文档

本项目采用单领域结构（single-context）：根目录 `GLOSSARY.md` 与 `docs/adr/`，不创建多领域映射或空业务源码目录。

## 阅读顺序

调查或修改前先阅读[术语表](../../GLOSSARY.md)，再阅读与当前改动相关的 `docs/adr/`。当前公开交付决策见 [ADR-0001](../adr/0001-public-prompt-distribution.md)。路由行为以[规则模板](../../config/AGENTS.model-routing.md)为真源，安装顺序以[配置入口](../../prompts/配置入口.md)为真源。

输出使用术语表的规范用语。术语缺失时确认是否确有新的领域概念，再按 domain-modeling 补充；不要把实现细节、测试日志或临时状态写进术语表。

发现行为与 ADR 冲突时指出具体冲突，取得实际决定后同步文档，不静默推翻已有决定。新增 ADR 只记录有长期价值的真实取舍，并遵守[公开文件边界](../../AGENTS.md#公开文件边界)：过程报告留在仓库外，新公开文件先获得授权并更新白名单。缺少文档时按技能要求继续必要工作，不为填充结构制造空文档。
